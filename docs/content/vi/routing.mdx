# Routes & màn hình

Các route chính của ứng dụng nằm trong `src/app`. Sidebar dashboard được tạo từ `src/configs/navigation/menuItems.tsx` và phụ thuộc vào CASL ability của user.

## Public routes

| URL | Màn hình |
| --- | --- |
| `/` | Landing page |
| `/login` | Đăng nhập |
| `/register` | Đăng ký |

Các route này được `AuthContext` xem là public và không gọi `/api/users/v1/me` khi khởi tạo.

## Dashboard routes

| URL | Vai trò |
| --- | --- |
| `/admin` | Tổng quan vận hành |
| `/admin/space-monitoring` | Giám sát không gian nhà máy, zone, line, machine |
| `/admin/machines` | Danh sách và trạng thái máy |
| `/admin/staff` | Quản lý công việc nhân sự |
| `/admin/setting` | Cài đặt tài khoản |
| `/operator/tasks` | Bảng tác vụ của operator |
| `/operator/my-reviews` | Danh sách review của operator |

## Cách thêm màn hình mới

1. Tạo `page.tsx` trong `src/app/(dashboard)/...`.
2. Tạo component con trong `_components` nếu màn hình đủ lớn.
3. Thêm endpoint vào `src/services/endpoints.ts` nếu cần API mới.
4. Thêm service method trong `src/services`.
5. Thêm permission subject/action nếu route cần kiểm soát truy cập.
6. Cập nhật `ROUTE_ACCESS` trong `src/configs/permissions/routeAccess.ts`.
7. Thêm item vào `src/configs/navigation/menuItems.tsx` nếu cần xuất hiện ở sidebar.
8. Cập nhật docs route này.

## Quy ước component trong route

Các component chỉ phục vụ một page nên đặt trong thư mục `_components` cạnh page đó. Component dùng lại nhiều module mới đưa vào `src/components/shared`.
