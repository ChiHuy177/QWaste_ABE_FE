# Qwaste v2

Qwaste v2 là ứng dụng web quản trị vận hành nhà máy, tập trung vào quản lý máy móc, không gian sản xuất, lệnh sản xuất, tác vụ vận hành, giám sát năng lượng và phân quyền người dùng.

Tài liệu này dành cho developer và người vận hành kỹ thuật của dự án. Nội dung ưu tiên cách chạy dự án, cấu trúc code, luồng dữ liệu, các module chính và quy ước khi mở rộng tính năng.

## Công nghệ chính

| Nhóm | Công nghệ |
| --- | --- |
| Framework | Next.js App Router |
| UI | React, Ant Design, lucide-react |
| State | Redux Toolkit, React Context |
| Data fetching | Axios, service layer, BFF route |
| Form | React Hook Form, Zod, Ant Design Form |
| Realtime | SockJS, STOMP |
| Phân quyền | CASL ability |
| i18n | i18next, react-i18next |
| Test | Jest, Testing Library |
| Deploy | Docker, Docker Compose, GitHub Actions |

## Cấu trúc repo liên quan

```txt
.
├── src/                    # Source chính của Qwaste frontend
│   ├── app/                # Next.js App Router
│   ├── components/         # Shared UI components
│   ├── configs/            # Branding, theme, navigation, permissions
│   ├── contexts/           # Auth, ability, error, websocket
│   ├── hooks/              # Shared hooks
│   ├── services/           # Service layer gọi API
│   ├── stores/             # Redux stores
│   └── types/              # TypeScript domain types
├── docs/                   # Nextra docs site
├── scripts/                # Deployment scripts
├── Dockerfile
└── docker-compose.yml
```
